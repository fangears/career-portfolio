# 多项目知识管理 MCP

角色：方案设计与开发

## 背景

Codex 同时处理多个项目时，项目入口、知识说明、运行方式和维护状态难以持续管理。

## 关键工作

- 设计只读项目注册表和稳定项目 ID，把项目元数据与知识文档统一建模
- 提供 MCP 查询能力，使 Codex 能按项目获取路径、概览、维护说明和关联资料
- 建立注册格式、维护工作流、WSL 部署和自动化测试文档

## 结果

- 形成知识库模式的多项目管理系统，降低跨项目上下文重复描述与入口查找成本。
- 本职业知识库按明确边界保持独立，不登记到 Project Hub。

技术：TypeScript、Node.js、MCP、JSON Schema、WSL、Git
